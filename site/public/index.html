Three layers of trust

An agent with a stopping condition.

Language understanding belongs to the model. Policy belongs to code. The final decision belongs to a person.

Typed extraction

PydanticAI turns a receipt into a validated InvoiceData object: vendor, date, total, currency, line items, category and confidence. Malformed output is rejected before it reaches the ledger.

Deterministic policy

Four checks run in Python: category budget, approved vendor, duplicate history and a $500 auto-approval ceiling. Same input, same result, every time.

A pause you can audit

Flagged invoices stop at PENDING_REVIEW. The extraction, every tool payload and the reviewer's decision are stored as an ordered trace.

The loop

Read. Check. Route. Decide.

  1. 01

    Read the receipt

    The extraction agent returns a strict InvoiceData model. In demo mode a deterministic parser does the same work, so the workflow runs without an API key.

    PydanticAI
  2. 02

    Check company policy

    Budget limit, vendor allow-list, duplicate history and the approval ceiling run as plain Python functions against data/policies.json and the SQLite ledger.

    Python
  3. 03

    Route the invoice

    A clean invoice at or below $500 is auto-approved. Any failed check, duplicate or larger total becomes PENDING_REVIEW with a machine-readable reason.

    State machine
  4. 04

    Record the decision

    A reviewer approves or rejects with an optional note. The decision is appended to the trace and the status becomes terminal.

    Human

        Architecture

        Built to explain itself.

        01 / Agent

        PydanticAI

        Structured output, dependency injection and function tools. The model can consult policy while extracting; it cannot approve an invoice.

        02 / Gate

        Deterministic tools

        Budget, vendor and duplicate checks query local policy and the ledger. Their payloads are the only inputs to routing.

        03 / Ledger

        SQLite and trace

        Each audit stores its invoice, policy results, ordered trace and human decision. Terminal decisions are immutable.
